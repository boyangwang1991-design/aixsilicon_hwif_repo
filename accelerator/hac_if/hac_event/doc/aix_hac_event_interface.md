## 7. 语义与约束

- **valid_ready**：`event delivered via valid/ready + event payload; interrupt generated by Shell from event policy`
- **no_silent_drop**：`error events must not be silently dropped before consumption`
- **fatal_sticky**：`fatal events have independent sticky state; soft reset must not clear diagnostic evidence by default`
- **core_no_irq**：`Core does not emit CPU interrupt protocol directly`

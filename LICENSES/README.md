# LICENSES

本目录存放本仓库及所引用第三方代码的许可证文本。

## 约定

1. 本仓库自研代码默认采用 **Apache-2.0**（待法务正式确认后更新）；
2. 引入任何第三方代码时：
   - 将对应 SPDX 许可证完整文本放入本目录（命名 `<SPDX-ID>.txt`）；
   - 在文件头使用 SPDX-License-Identifier 标注；
   - 更新仓库根目录 `NOTICE`；
   - 对 PULP 系列项目（Solderpad / Apache-2.0）按文件逐一审查。
3. 商业协议规范正文（如 AMBA 规范）不复制进仓库，仅在 Contract 中记录受控引用。
